# Centromere selection

This directory contains a python script that extracts centromere contigs from genome assemblies.

| File | Description |
| --- | --- |
| `get_centromeres_from_fasta.py` | Maps centromere flanks to an assembly, infers and extracts centromeric intervals, orients them relative to T2T, and writes per-chromosome FASTA files and a strand-annotated centromeric BED file. |
